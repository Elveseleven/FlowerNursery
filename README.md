# Flower Nursery Web Application

A simple web application for managing a flower nursery. Helps workers plan care tasks and track watering needs for flower groups in greenhouses.

## Entities

- `Greenhouse` – a place where flower groups are grown.
- `Flower Group` – a group of flowers of the same species/variety placed in a specific greenhouse.
- `Watering Schedule` – planned watering dates for a selected flower group.

## Features

- Add, edit, delete greenhouses.
- Add, edit, delete flower groups.
- Assign flower groups to greenhouses.
- Plan watering dates for flower groups.
- Display upcoming watering tasks.
- Mark watering tasks as completed.
- View watering history for a selected flower group.

## Technology Stack 

- ASP.NET Core
- SQL Server
- HTML / CSS / JavaScript
